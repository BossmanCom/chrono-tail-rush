# Chrono Tail Rush

A quick pixel flyer for phones.

Dodge cat girls, techno trolls, and floating islands while the surreal landscape shifts through different time eras.

## Play
Open `index.html` in any modern browser, or enable GitHub Pages for a live link.

**Controls**
- **Phone**: Swipe up/down to fly • Tap to boost
- **Desktop**: Arrow keys / WASD • Space to boost

## Characters
- **Ani (Foxgirl)** – orange onesie, emerald twintails  
- **Cat Girl** – the armored black cat from the reference video  
- **Red Elf** – the red-haired flyer from the same video

All pure pixel, no external assets.

Made for a fun late-night drop with the followers.
